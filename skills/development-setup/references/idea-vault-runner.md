# Idea Vault Runnerの初期セットアップ

本手順は、利用者がIdea Vaultの実行環境の導入を依頼した場合に使用する。
スキルの作成依頼だけでは、エージェントは本手順の認証や配置を開始しない。

## 対象の特定

エージェントは、利用者が所有する3つのリポジトリを特定する。

| 対象 | 現在の導入先 | 初期設定の担当 |
|---|---|---|
| スキル配布 | `OseRen04/ideaPushSkill` | エージェントが導入済みのスキルを確認する。 |
| 企画管理 | `OseRen04/idea-vault` | エージェントが企画と時間設定を確認する。 |
| 実行管理 | `OseRen04/idea-vault-runner` | エージェントが非公開設定・コード・Secretsを確認する。 |

エージェントは、別ユーザーの設定へ `OseRen04` を流用しない。
エージェントは、実行用コードの `docs/OPERATIONS.md` と設定ファイルを確認する。
エージェントは、実際の導入済みバージョンに対応するコマンドを使用する。

## 工程

1. エージェントは、公式CLI・所有者・対象リポジトリを診断する。
2. エージェントは、必要なGitHub CLI認証と権限だけを設定する。
3. エージェントは、依頼済みの実行用リポジトリを準備する。
4. 利用者は、CI専用のCodexログインをブラウザで完了する。
5. エージェントは、依頼されたCI用Secretsを登録する。
6. 利用者は、GitHubの費用停止条件と実際の残枠を確認する。
7. エージェントは、許可された診断と認証実証を行う。
8. エージェントは、残る設定と運用開始条件を報告する。

エージェントは、完了済みの工程を診断結果に基づいて省略する。
エージェントは、既存のリポジトリや時間設定を無条件で作り直さない。

## CI用のGitHub権限

| Secret | 用途 |
|---|---|
| `RUNNER_GITHUB_TOKEN` | 所有者の開発先作成・実行状態更新・Secrets更新・使用量取得。 |
| `DEVELOPMENT_GITHUB_TOKEN` | 開発先のContents・Issues・Pull requestsの更新。 |
| `CODEX_AUTH_JSON` | CI専用のChatGPT認証。 |

エージェントは、管理用と開発用のGitHub認証を区別する。
エージェントは、開発用トークンへSecretsや管理設定の更新権限を要求しない。
利用者は、必要な権限を持つトークンをGitHub側で用意する。
利用者は、公式CLIの対話入力などの安全な経路でトークンを登録する。
エージェントは、トークンの会話への貼り付けを求めない。

```bash
gh secret set RUNNER_GITHUB_TOKEN --repo OWNER/REPO
gh secret set DEVELOPMENT_GITHUB_TOKEN --repo OWNER/REPO
```

GitHub CLIへのログインだけでは、CI用の権限設定は完了しない。
エージェントは、PC用のOAuth認証をCIへ無断で複製しない。
エージェントは、既存Secretsの存在だけで値や権限を推測しない。
エージェントは、変更依頼のない既存Secretsを上書きしない。

## 費用と実証

利用者は、予算の利用停止設定と請求サイクルを確認する。
現行Runnerは、公式使用量と利用者の最新確認データを照合する。
エージェントは、費用データを推測で埋めない。
費用データが古い・不明な場合、エージェントはCIの起動を止める。

`doctor` は、モデルを呼び出さずに設定を検証する。
`auth-check` は、費用条件を満たした場合だけCodexを実行する。
エージェントは、既存の依頼範囲にCIの動作確認が含まれる場合、実証を進める。
エージェントは、CIへの登録だけの依頼からモデルの実行を追加しない。
エージェントは、実証に必要な実行スイッチの変更を対象とともに明示する。
実証専用にスイッチを変更した場合、エージェントは実証後に元の設定へ戻す。
エージェントは、認証成功と更新認証の書き戻し成功を別々に報告する。

エージェントは、初期セットアップの完了から自動開発の開始を推測しない。
利用者は、時間指定と企画ごとの開発許可を別途指定する。
エージェントは、認証を理由に `agent_development` を変更しない。

現在の実行用コードの手順は、[運用手順](https://github.com/OseRen04/idea-vault-runner/blob/main/docs/OPERATIONS.md)を参照する。
