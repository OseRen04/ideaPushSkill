# 初期セットアップ

## セットアップ用プロンプト

```text
Idea Vaultプラグインの初期セットアップを進めてください。
私のGitHubアカウントはOseRen04です。
CI設定先は、私の非公開リポジトリOseRen04/idea-vault-runnerです。
CI専用認証とSecretsの設定、接続検証も対象です。
```

## 必要な認証作業

| 認証 | 用途 | あなたの操作 |
| --- | --- | --- |
| GitHub CLI | あなたの端末からのGitHub操作 | あなたは、GitHubの公式画面でログインと権限承認を行います。 |
| Codex（端末用） | あなたの端末でのCodex利用 | あなたは、OpenAIの公式画面でChatGPTへログインします。 |
| GitHub（CI用） | GitHub Actionsからのリポジトリ作成・更新 | あなたは、管理用と開発用のトークンを用意します。 |
| Codex（CI専用） | GitHub ActionsでのCodex実行 | あなたは、CI専用のChatGPTログインを行います。 |

## プロンプトで行うこと

- エージェントは、Idea Vaultプラグインと[セットアップ用スキル](SKILL.md)の利用可否を確認します。
- エージェントは、あなたの端末でCLI・既存認証・不足する権限を確認します。
- エージェントは、不足する認証を案内します。利用可能な認証がある場合、エージェントは再認証を省略します。
- エージェントは、あなたの非公開リポジトリへCI用Secretsを登録します。
- エージェントは、GitHubの費用停止設定と残枠の確認をあなたへ依頼します。権限と費用条件が揃った場合だけ、エージェントはCIの接続を検証します。
- エージェントは、端末とCIの認証結果を分けて報告します。エージェントは、残作業と担当者も報告します。
