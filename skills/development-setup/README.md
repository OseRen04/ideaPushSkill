# 初期セットアップの流れ

1. あなたは、初回導入時や認証失効時に[スキル](SKILL.md)へ「初期セットアップを進めて」と依頼します。
2. エージェントは、あなたの端末でCLI・認証・権限を確認します。利用可能な既存認証がある場合、エージェントは再認証を省略します。
3. エージェントは、不足する権限と必要な作業を案内します。あなたがブラウザを操作できる時点で、エージェントは認証を開始します。
4. あなたは、GitHubの公式画面で本人認証と権限承認を行います。あなたは、OpenAIの公式画面でCodex用のChatGPTログインを行います。コードが期限切れの場合、エージェントは公式CLIで新しいコードを取得します。認証後、エージェントはCLIで認証結果を確認します。
5. CI設定も依頼する場合、あなたはCI用トークンを準備します。あなたは、CI専用のCodexログインをブラウザで完了します。
6. エージェントは、依頼されたCI用Secretsを登録します。登録先は、あなたの非公開リポジトリ `OseRen04/idea-vault-runner` です。
7. CI検証も依頼する場合、あなたはGitHubの費用停止設定と残枠を確認します。権限と費用条件が揃った場合だけ、エージェントはGitHub Actionsで認証と更新認証の保存を検証します。不足や不明がある場合、エージェントはCI検証を保留します。
8. エージェントは、ローカル認証とCIの検証結果を分けて報告します。エージェントは、残作業と担当者も報告します。
