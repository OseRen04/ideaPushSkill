# 初期セットアップの流れ

あなたは、[初期セットアップスキル](SKILL.md)へ「初期セットアップを進めて」と依頼します。

1. エージェントは、あなたのCLI・認証状態・対象リポジトリを診断します。既存の認証が使える場合、エージェントは再認証を省略します。
2. エージェントは、不足する権限と必要な作業を案内します。あなたは、本人認証に使うブラウザを準備します。
3. エージェントは、必要なGitHub認証のURLとコードを案内します。あなたは、GitHubの公式画面で本人認証を行います。
4. エージェントは、必要なCodex認証を開始します。あなたは、OpenAIの公式画面でChatGPTアカウントへログインします。
5. CI設定が依頼に含まれる場合、あなたは必要なCI用トークンを用意します。エージェントは、対象CIへ専用認証とSecretsを登録します。
6. エージェントは、権限と費用条件が揃った範囲で接続を検証します。エージェントは、結果と残作業を報告します。期限切れの場合、エージェントは新しいコードで未完了の認証を再開します。
