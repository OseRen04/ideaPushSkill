# 初期セットアップ

## セットアップ用プロンプト

```text
Idea Vaultプラグインの初期セットアップを進めてください。
利用するアカウント・保存先・機能は、未確認の場合だけ私に質問してください。
```

## 必要な認証作業

| 認証 | 必要になる場合 | 利用者の操作 |
| --- | --- | --- |
| GitHub CLI | 利用者の端末からGitHubを操作する場合 | 利用者は、GitHubの公式画面でログインと権限承認を行います。 |
| Codex（端末用） | 利用者の端末でCodexを使う場合 | 利用者は、OpenAIの公式画面でChatGPTへログインします。 |
| GitHub（CI用） | GitHub Actionsでの自動開発を利用する場合 | 利用者は、管理用と開発用のトークンを用意します。 |
| Codex（CI専用） | GitHub Actionsでの自動開発を利用する場合 | 利用者は、CI専用のChatGPTログインを行います。 |

## プロンプトで行うこと

- エージェントは、Idea Vaultプラグインと[セットアップ用スキル](SKILL.md)の利用可否を確認します。
- エージェントは、利用者のGitHubアカウント・保存先・利用機能を確認します。未確認の項目だけ、エージェントは利用者へ質問します。
- エージェントは、実行環境と既存認証を確認します。エージェントは、不足する認証と権限だけを案内します。
- CI設定を依頼された場合、エージェントは利用者が指定した非公開リポジトリへSecretsを登録します。
- CI検証を依頼された場合、エージェントは費用停止設定と残枠の確認を利用者へ依頼します。権限と費用条件が揃った場合だけ、エージェントはCIの接続を検証します。
- エージェントは、端末とCIの認証結果を分けて報告します。エージェントは、残作業と担当者も報告します。
