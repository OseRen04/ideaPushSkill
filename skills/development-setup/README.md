# 初期セットアップの流れ

初期セットアップは、あなたのGitHub操作とCodex利用に必要な認証を整える作業です。あなたは、初回導入時や認証失効時に[初期セットアップスキル](SKILL.md)へ「初期セットアップを進めて」と依頼します。

エージェントは、あなたの端末で公式CLIと既存の認証状態を確認します。利用可能な認証がある場合、エージェントは再認証を省略します。エージェントは、不足する権限と必要な作業を案内します。

あなたがブラウザを操作できる時点で、エージェントは必要な認証を開始します。あなたは、GitHubの公式画面で本人認証と権限承認を行います。あなたは、OpenAIの公式画面でCodex用のChatGPTログインを行います。コードが期限切れの場合、エージェントは新しいコードで未完了の認証を再開します。

CI設定も依頼する場合、あなたはCI用トークンを準備します。エージェントは、あなたの非公開リポジトリ `OseRen04/idea-vault-runner` のSecretsへCI専用認証を登録します。CI検証も依頼する場合、あなたはGitHubの費用条件を確認します。権限と費用条件が揃った場合だけ、エージェントはCIの接続を検証します。エージェントは、ローカル認証とCIの検証結果を分けて報告します。エージェントは、残作業と担当者も報告します。
