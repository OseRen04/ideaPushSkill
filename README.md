# ideaPushSkill

ChatGPTで議論したアイデアと、企画ごとの自由なメモをGitHubに保存するスキルです。

- スキル：[Idea Vault](skills/idea-vault/SKILL.md)
- `idea.md`：現在のアイデア名と概要。
- `discussions.md`：議論要約とChatGPTの会話URL。
- `memo.md`：各企画フォルダ直下に1つ。書式自由で原文を保存・追記・編集します。
- 既存のGitHub連携を接続し、保存先リポジトリを指定して使います。
- 「このアイデアを保存して」「この企画にメモして」で保存。生成だけでは書き込みません。
